Operations plugin

Newsroom agent ops

Recurring newsroom work with durable state, bounded authority, and proof after every external action.

Works in: Claude Code; Codex: not yet runtime-tested.

Shared capability contract

Supply capabilities

Connect the task tracker, contacts store, calendar, mail reader, authorized sender, send log, chat, notifier, peer mailbox, and CI service that fit your environment.

Write the policy first

Every external action needs a written policy that states who may send or change what, to whom, and when. Project instructions remain authoritative.

Skills

Unattended agent runs

Leases, checkpoints, recovery, delivery checks, and resource limits.

Scheduled briefing

Current, phone-readable newsroom briefings.

Deadline and reply tracking

Due dates, acknowledgments, waiting states, and appeals.

Email request intake

Allowlisted requests and untrusted-content controls.

Document delivery

Inspect, share, send, and verify documents.

Chat mention triage

Track distinct work without duplicate replies.

Record reconciliation

Canonical contacts, tasks, interactions, and privacy.

Multi-agent coordinator

Durable prompts, watches, review gates, and cleanup.

Issue pool progression

Claims, review, release, live checks, and cleanup.

Start with the simpler run model

The public autonomy kit provides a process-per-run starter. Move to a persistent supervised session only when the recovery and resource controls justify the added complexity.

Install

/plugin marketplace add jamditis/claude-skills-journalism
/plugin install newsroom-agent-ops@claude-skills-journalism

npx skills@latest add https://github.com/jamditis/claude-skills-journalism/tree/master/newsroom-agent-ops \
  --skill '*' --agent codex --copy -g -y
