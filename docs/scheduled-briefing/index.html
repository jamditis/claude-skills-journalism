Operations skill

Scheduled briefing

A current, phone-readable view of decisions, schedule, new work, and waiting items.

Works in: Claude Code; Codex: not yet runtime-tested.

What it reconciles

Schedule

Collapse duplicate calendar entries and keep the timezone visible.

Work

Give every supported action an owner and due date.

Evidence

Label sources and state what is unavailable or unverified.

Brief order

  1. Decisions the editor must make.
  2. Today's dated schedule.
  3. New work with an owner and due date.
  4. Waiting items with the person or event that can unblock them.
  5. Source limits and verified record changes.

Quiet check-ins stay quiet

Do not create tasks that only restate a check-in. Do not mark work complete from silence or an old snapshot.

Authorization boundary

Return a draft unless a written policy authorizes the send or record change. The project instruction file controls.

Install

Claude Code, as part of the newsroom-agent-ops plugin:

/plugin marketplace add jamditis/claude-skills-journalism
/plugin install newsroom-agent-ops@claude-skills-journalism

Codex, or any agent that reads Agent Skills from .agents/skills:

npx skills@latest add jamditis/claude-skills-journalism \
  --skill scheduled-briefing --agent codex --copy -g -y
