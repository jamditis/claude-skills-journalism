Visual audits

Inspect the whole composition, then make the findings actionable.

Portable workflow preview. Check available tools and approval requirements in your own environment before acting.

The workflow

  1. Identify the audience, task, reference design and surfaces being reviewed.
  2. Capture the real full frame at the relevant desktop and mobile sizes.
  3. Check hierarchy, spacing, legibility, contrast, overflow, controls and content accuracy.
  4. Exercise repeated and interrupted interactions, keyboard focus and reduced motion where applicable.
  5. Record each finding with evidence, severity, affected location and a concrete proposed correction.
  6. Recheck the actual changed output rather than assuming a code edit fixed the visible problem.

Evidence, not decoration

A screenshot of another page does not validate this page. A cropped view can hide clipping or layout failures. Label mockups and analysis-only outputs honestly.

Keep review separate from implementation

Audit authority does not automatically authorize repository writes, publishing or deployment. Scope any implementation separately.
