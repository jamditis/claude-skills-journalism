A cleaner home screen
Projectivy replaces the stock home screen after its Home activity is verified. The existing streaming apps and sign-ins stay in place.
Optional packages disabled
Advertising, personalization, feedback, and game packages are reviewed against the device and how you use it. App data stays on the device.
Less motion, if you want it
Turn off window and app-transition animations, plus the launcher's wallpaper transitions. Save the original values for later.
A restore path
Keep a record of the original launcher, package states, and settings. Restore the stock Home app before removing its replacement.

From connection
to a checked restart.

A network connection starts the job. Readback and recovery finish it.

  1. Connect to the right device

    Resolve the named TV, obtain its ADB authorization, and confirm the model and Android version. Wireless debugging may need a Wi-Fi connection and a separate pairing port.

  2. Save, then change

    Record the installed apps, disabled packages, Home handler, and animation settings. Install and test the new launcher before disabling the old one.

  3. Check daily use

    Open Settings and representative streaming apps. Send Home and check the foreground activity. Read back the package and motion settings.

  4. Restart with a recovery path

    Confirm a new boot and check that the setup persists. If Tailscale does not reconnect, a known LAN endpoint can allow the existing app to be reopened.

The Streamer profile comes from a real setup

The included reference records a Google TV Streamer on Android 14. Launcher replacement, Settings, app launches, reduced motion, and restart persistence were checked. Playback, casting, voice input, and physical remote input remain separate checks.

Package names and dependencies differ across TVs. A successful setup on one model is a starting point for inspection on the next.

Keep the TV
useful.

The workflow protects the services behind streaming, casting, voice control, the remote, updates, accessibility, and networking. It leaves unknown system packages enabled.

A successful app launch proves that the app opens. Playing a video, casting from a phone, and testing the microphone each need their own check.

The free launcher supports the cleanup and reduced-motion setup. Premium customization is optional and follows the user's choice.

Install TV debloat

The skill uses the open Agent Skills format. It needs Android Platform Tools and authorized access to the TV. Tailscale is optional.

Claude Code plugin

/plugin marketplace add jamditis/claude-skills-journalism
/plugin install dev-toolkit@claude-skills-journalism

Invoke it as /dev-toolkit:tv-debloat, or describe the TV cleanup you need.

Install a single skill

npx skills@latest add jamditis/claude-skills-journalism --skill tv-debloat

Choose your supported agent during installation. In Codex, invoke it as $tv-debloat.

Try a request

Use tv-debloat to clean up my Google TV Streamer. Keep the streaming apps, reduce animations, and save the original settings so I can restore them.
