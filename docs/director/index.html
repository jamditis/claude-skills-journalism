Development skill

Director

Updated Aug 21, 2026

Direct, decide, delegate, and review without taking over implementation work.

Use this skill when

  • The user explicitly wants the top-tier model to direct the current request.
  • The environment policy defines lower-tier agents or models for execution.
  • Research, edits, tests, and commands must stay delegated.

Role contract

Director work

Set the outcome, divide the work, make decisions, resolve conflicts, and review the results.

Delegated work

Send research, code, file changes, tests, and command execution to the configured lower-tier agents.

Policy-driven routing

The skill reads the applicable CLAUDE.md policy for the current user and project.

It does not contain a home-directory path or fixed model name. Each environment keeps its own routing policy.

If required delegation is unavailable, the director stops and tells the user. Activating the role does not grant new authority.

Install and invoke

The plugin form is namespaced:

/plugin install dev-toolkit@claude-skills-journalism
/dev-toolkit:director

For the literal /director command, install the standalone skill:

mkdir -p ~/.claude/skills
cp -r dev-toolkit/skills/director ~/.claude/skills/
/director
