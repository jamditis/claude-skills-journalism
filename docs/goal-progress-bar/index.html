Goal progress bar

Render honest weighted progress from a small JSON tracker.

Use this skill when

  • A task has at least three meaningful steps.
  • Review, release, live checks, or requester approval are part of completion.
  • Readers need a short checkpoint that is derived from the recorded work.

Tracker contract

Weight the rows

Use one row per deliverable or proof. Give large or critical rows more weight.

Keep proof honest

A proof row reaches 1.0 only after real evidence. Never delete a row to raise the result.

Back up before edits

Copy the tracker before changing fractions, weights, or blocked status.

Render every value

Paste the script output without changing the percentage, bar, or row list.

Run the script

python3 <skill-root>/scripts/progress.py my-goal-progress.json "Goal name"
python3 <skill-root>/scripts/progress.py my-goal-progress.json "Goal name" --chat

Run it from the task folder that holds the tracker. <skill-root> is the installed skill folder. The plain mode uses an ASCII bar. The optional chat mode uses common emoji shortcodes. An empty tracker reports 0% without an error.
