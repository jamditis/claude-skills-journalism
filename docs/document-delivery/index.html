Operations skill

Document delivery

Updated Oct 23, 2026

Keep document creation, sharing, sending, and publication as separate states.

Works in: Claude Code; Codex: not yet runtime-tested.

Inspect the final artifact

Editable source

Use native headings, lists, tables, links, alt text, and page structure.

Export

Check every page for clipping, fonts, links, contrast, blank pages, and pagination.

Verify access and delivery

  1. Confirm sharing scope and named-recipient access.
  2. Confirm the exact final attachment and recipient.
  3. Send once through the authorized capability.
  4. Read back the send record and recipient-visible copy.
  5. Update tracking with the exact delivered version.

Related document skills

Use pdf-design for report and proposal design. Use document-design for print-ready HTML and PDF output.

Authorization boundary

Draft authority does not grant sharing, sending, or publication authority. The written policy and project instruction file control.

Install

Claude Code, as part of the newsroom-agent-ops plugin:

/plugin marketplace add jamditis/claude-skills-journalism
/plugin install newsroom-agent-ops@claude-skills-journalism

Codex, or any agent that reads Agent Skills from .agents/skills:

npx skills@latest add jamditis/claude-skills-journalism \
  --skill document-delivery --agent codex --copy -g -y
