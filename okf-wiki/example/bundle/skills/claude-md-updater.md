# claude-md-updater skill

Use this skill when the user asks to update project instructions, save a durable lesson,
or persist context. Resolve the canonical `AGENTS.md` or `CLAUDE.md`, scan for hard-won
lessons and stable workflows, then propose a scoped diff for approval before writing.

Part of the [dev-toolkit plugin](../plugins/dev-toolkit.md). Source: `dev-toolkit/skills/claude-md-updater/SKILL.md`.
