# private-secret-scanning skill

Local Gitleaks scans for staged changes, push ranges, and full history in private
repos, with redacted reports. Use to block committed secrets without GitHub Secret
Protection.

Part of the [security-toolkit plugin](../plugins/security-toolkit.md). Source: `security-toolkit/skills/private-secret-scanning/SKILL.md`.
