# dev-toolkit plugin

Ten skills: accessibility (WCAG 2.2), Electron patterns, mobile/remote debugging,
irreversible-decision discipline, Python data pipelines, test-first bug fixing,
AI-assisted development, ethical web scraping, no-build frontend patterns, and
web-UI taste. Install with `/plugin install dev-toolkit@claude-skills-journalism`.
